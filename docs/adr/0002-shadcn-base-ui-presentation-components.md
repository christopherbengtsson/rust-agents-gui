# shadcn/ui with Base UI and Tailwind

Use official shadcn/ui source components backed by Base UI, with Tailwind and shared theme variables, for the agreed React presentation. The user accepted editable components and established interaction primitives as a starting point for the compact Conductor-inspired interface, together with the responsibility to review upstream changes against local customizations.

Add components as working screens need them, beginning with the application shell and repository registration. Keep product semantics and execution/recovery ownership under the [MVP contract](../MVP.md); the component toolkit does not define application state or authorize deferred capabilities.

Use the repository-local [official shadcn skill](../../.agents/skills/shadcn/SKILL.md) for component work under repository policy.
