## Delivered behavior

The Codex adapter accepts stable SemVer releases >= 0.169.0 without an upper
version limit; prereleases, malformed output and older versions are rejected.
LF/CRLF and valid build metadata are supported using locked semver 1.0.28.
Readiness carries the actual detected version into SetupEvidence. Both readiness
and browser login share initialize/initialized plus a successful
`account/gatewayOAuth/read` before subsequent authenticated requests on each new
connection. Support is distinct from authentication; additional fields and bounded
informational notifications are accepted. Required fields, exact reply/attempt
identity, deadlines, cancellation, stale evidence and owned cleanup remain strict.

The typed target now exposes `minimum_supported_version`; Technical details show
Minimum runtime and Observed runtime. Recovery guidance permits newer stable
releases after required checks. Supervisor protocol is **13**: use matching peers
and fresh private development state. The current pure serialization corpus is
`contracts/observations-v13.json`; v12 remains historical evidence.

The MVP records the provider-wide principle; individual adapters retain their own
provider's compatibility mechanics. There is no provider framework or CLI/PTY
implementation. Ticket 03 now waits for checked 02a acceptance and this handoff.
