red not-found and confirmed setup failures; contextual native executable selection.

uses inherited PATH, bounded interactive/login-shell PATH recovery and conventional

selected paths never silently fall back; logical symlinks persist while resolved

a remembered location independently of authentication. Selection intent/reply
reconciliation shares the provider observation architecture and fences delayed
requests. Persistence stores only non-secret location/action identity.

Historical corpus 13 is retained as evidence, with no active old-format reader,
migration or mixed-version support. No dependencies were added. Existing minimum
stable Codex **0.169.0**, initialize/gateway checks and runtime-owned credentials

retains official revision `d32063f96c2dff1dc96af839b3952abb6acfeda4`; protocol
changes expose a local validation checkpoint, adding no native request method.
