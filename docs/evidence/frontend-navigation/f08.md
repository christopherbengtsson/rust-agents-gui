## Defects and retained coverage

1. **macOS staged executable could be killed despite matching bytes/signature.**
   Overwriting an existing staged executable inode caused SIGKILL while Cargo's
   executable and a new-inode copy ran. Sidecar preparation now copies to a unique
   same-directory temporary file and renames it into place, then removes temporary
   residue. This follows Apple's [Updating Mac Software](https://developer.apple.com/documentation/security/updating-mac-software)
   inode/signature-cache guidance. Existing provenance, exact Cargo executable and
   hash assertions remain. Eight substituted tooling cases pass, including copy
   and publication failure. [Initial probe](f08/sidecar-execution-probe.json) and
   [corrected execution](f08/sidecar-execution-fixed.json) retain the distinction.
2. **Nested WebView reload left the old native feed owned.** The new document's
   subscription was rejected Busy and observation delivery stopped. The owning Rust
   connection now validates the replacement, bounds admission to one replacement,
   physically stops/joins its previous worker, then revalidates owner/shutdown
   before starting. Tauri only awaits this operation. Ordinary strict admission
   and exact stop/ack matching remain unchanged. Three new controlled cases prove
   join-before-replace, competing replacement rejection, invalid target preservation,
   cancellation ownership/permit retention, and distinct-ID late-stop isolation.
3. **Settings retained hidden collection interests.** Both app-lifetime action
   hooks remain constructed, but list/detail interests now release while Settings
   is visible. Retained action interests remain independent. Three new routed
   regressions establish no hidden read fan-out, dirty refresh on return, and
   registration/workspace action settlement without replay or navigation theft.
   The actual 310-second expiry and withheld-reply checks below confirm the seam.

All previous assertions remain; no tests were deleted or replaced. There is no
lost coverage mapping. Added cases extend existing owning-module/tooling/routing
suites selected by the configured gate. The [TypeScript audit](f08/typescript-audit.json)
finds no new `any`, assertions, suppression comments, declaration shims or weakened
checking. [Independent review](f08/review.md) records Standards and Spec separately.
