## Defect found and fixed

Actual WebView tracing found **453 inspection reads in a six-second visible
interval** with a retained selected preview. A newer hint dirtied that preview,
then a pending summary could not refresh it. The actor treated the old preview as
an immediate follow-up obligation and repeatedly reread the pending summary.
[Pre-fix trace](f04g/current-before-fix-webview.json) and raw exports preserve this
failure; hidden delivery correctly stopped feature reads.

Preview freshness now participates only when the summary is ready to supply its
target. Pending/failed summaries wait for their own newer hints or explicit
refresh; Query retains last-good content and the actor retains physical work.
A bounded controlled regression failed with three reads instead of one, then
passed with no further reads over controlled time and recovery on a newer hint.
The first timer-driven repro starved its timer and was explicitly terminated;
its log/status is retained. All twelve inspection actor scenarios pass, including the reviewer-found retained-error variant.

No wire/API/dependency version changed. No new TypeScript escape, declaration shim,
checking relaxation, generic observation framework or integration-test framework
was introduced. Actual-process checks extend the existing opt-in gate; the Python
socket qualifier is explicit and excluded from application units.
